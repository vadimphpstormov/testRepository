# ПРОФзона.инфо — новый сайт

Редизайн сайта [profzoneinfo.ru](https://profzoneinfo.ru): одностраничный адаптивный сайт на чистом HTML/CSS/JS, без сборки.

## Структура
- `index.html` — разметка (герой, о компании, услуги, этапы работы, инструменты, журнал, партнёрам, контакты)
- `css/styles.css` — стили, адаптив (десктоп / планшет / телефон)
- `js/main.js` — мобильное меню, анимации появления, подсветка меню, валидация формы

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Что настроить
- Телефон, e-mail и мессенджеры — добавьте в блок «Контакты» (`index.html`).
- Отправка формы — укажите адрес обработчика в `FORM_ENDPOINT` (`js/main.js`).
- Статьи журнала — замените карточки в блоке «Журнал» на реальные публикации.
